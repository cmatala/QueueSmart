# QueueSmart

## Assignment 1 – Initial Thoughts and System Design

QueueSmart is a responsive web-based smart queue management application.

## Design Decisions

- **Platform:** Responsive web application
- **Methodology:** Agile principles with Scrum-inspired practices
- **Notifications:** Email
- **Queue Priority:** Primarily arrival time, with defined priority levels when necessary
- **Wait-Time Estimation:** Number of people ahead × expected service duration
- **External System:** One Email/Notification Service
